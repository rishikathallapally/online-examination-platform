# 📝 EXAMLY — Online Examination & Assessment Platform

EXAMLY is a responsive, frontend-based online examination platform built with React. It provides a simple and interactive environment where users can take timed exams, manage their answers, track their progress, and review their results.

The application includes exam navigation, automatic scoring, progress saving, and a personalized dashboard to demonstrate practical frontend development skills.

## ✨ Features

### 📊 Dashboard
- Overview of available examinations.
- Summary of exam activity and performance.
- Easy navigation to different sections.

### 📝 Examination Experience
- Timed examinations with a countdown timer.
- Multiple-choice questions with answer selection.
- Question-by-question navigation.
- Visual indicators for current, answered, unanswered, and marked questions.
- **Mark for Review:** Mark questions to revisit before submitting.
- Toggle review marks whenever needed.
- Submit confirmation based on user preferences.
- Automatic submission when the timer reaches zero.

### 💾 Save & Resume
- Automatically saves exam progress in browser local storage.
- Restores previously selected answers.
- Remembers the current question and remaining time.
- Preserves questions marked for review.
- Clears saved progress after exam submission.

### 🏆 Results & Exam History
- Automatic score calculation after submission.
- Displays examination results.
- Stores completed exam history locally.
- Allows users to review their previous performance.

### ⚙️ Profile & Settings
- Profile information section.
- Customizable examination preferences.
- Dark mode support.
- Settings are stored locally in the browser.

### 🔐 Login & Navigation
- Demo login experience.
- Protected application routes.
- Client-side navigation using React Router.
- Custom 404 page for unavailable routes.

### 📱 Responsive Design
- Responsive layouts for desktop, tablet, and mobile.
- Consistent interface across screen sizes.
- Accessible form controls and interactive elements.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/rishikathallapally/online-examination-platform.git
```

**2. Navigate to the project folder**

```bash
cd online-examination-platform
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL displayed in your terminal to explore the application.

## ⚠️ Project Scope

EXAMLY is a **frontend-only demonstration project**. It does not use a backend server or database. Login, examination data, settings, results, and saved progress are handled on the client side using browser Local Storage.

The demo login is intended for exploration and is not a production authentication system. The application does not provide server-side authentication, secure exam storage, or real-time multi-user functionality.
